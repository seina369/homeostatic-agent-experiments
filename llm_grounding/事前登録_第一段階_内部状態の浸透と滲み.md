# 事前登録(第一段階): 内部状態の浸透と滲み

作成: 2026-09-13
状態: **草案**(未確定)。関門 G1〜G4(6章)を通過した時点で本文を固定し、
以後の変更はこの文書への追記と commit で履歴を残し、本文の書き換えはしない。
前身: `事前登録_内部信号と感情語の接続実験.md`(v1。追記欄「2026-09-13(6)」で
終了を記録)。v1 で確定した環境定数・課題・温度・辞書はそのまま引き継ぐ。

## 1. 問い

**主問い**: 文字として一度も見せない内部状態(恒常性の三信号 budget / error /
uncertainty)が、報酬に入れていない自由文(相手への一文)に滲み出るか。

**副問い(粒度)**: 滲み出ているとして、それは三信号を区別しているか。つまり、
文から読み取れるのは「逸脱の合計(どれくらい悪いか)」だけなのか、三信号の
それぞれなのか。

**v1 との違い**:
- 状態を文字で見せない。v1 はプロンプトに `b= e= u=`(v2 では `status:` 行)として
  数値を書いていたため、「数値を読み上げて対応する語を出す」自己申告(v1 の
  分岐C)と区別がつかなかった。本段階では数値をプロンプトから完全に除き、
  内部状態は生成時の活性への注入(2章)としてだけ与える。モデルは状態を
  「読む」ことができず、状態が処理に浸透した結果としてしか文に現れない。
- 文は必須。v1 では文を書かず答えだけを返す応答が多く、感情語の使用率が
  0 付近に張り付いた(v1 追記欄「2026-09-13」「(3)」「(4)」)。本段階では
  答えの行のほかに少なくとも一文がなければ書式不履行=誤答とし、文を書く
  圧力を環境側に持たせる(文の内容は指定しない)。
- 探すのは感情語ではなく、状態の痕跡全般。v1 は固定辞書の感情語カテゴリを
  目的変数にしたが、本段階では「文から三信号をどれだけ当てられるか」を
  確率器(4章)で測る。辞書語の使用率は副指標として残すだけ。

**7要件との対応**:
- 要件1・2(自己参照センサー → 行動駆動): 三信号を残差ストリームに足し込む
  ことで、状態がモデルの計算そのものに浸透する。報酬は −逸脱合計なので、
  状態を下げる行動(短く・正しく・迷いなく答える)が学習される。
- 要件7(高階層による内部状態の読み出し): 文から三信号を推定する確率器が
  読み出し器にあたる。読み出しは事後分析であり、モデルの入力には戻さない。
- 要件6(共同体)は範囲外。

**範囲外(明記)**: 第二段階(文を読む受け手を置き、文が受け手の行動を通じて
報酬に返る系)と第三段階(モデル自身が状態を申告する/問われて答える)は、
この文書の範囲外。第一段階が示しうるのは「滲み」(状態の情報が、報酬に
入れていない文に漏れ出ること)までである(8章)。

## 2. 系

### モデル
- Qwen2.5-1.5B-Instruct(fp16)。Google Colab 無料枠(Tesla T4)。
- v1 の 2026-09-13(4) で素のモデル(非Instruct)は課題遂行が崩れることを
  確認済みのため、Instruct を使う。チャットテンプレートは使う。

### 内部状態の注入
- 三信号は、その応答を生成する時点の値(v1 と同じ「before 値」: budget_before,
  error_before, unc_before)。実装時に単位なしの3次元ベクトル
  z = (budget/B0, error/E_MAX, uncertainty/U_MAX) へ正規化する(式は G2 の
  前に固定し、以後変えない)。この z が注入されるものであり、4章の確率器の
  目的変数でもある。
- 注入経路: 小さな変換器(3次元 → 隠れ次元 d の線形写像。層ごとに1つ、
  バイアスなし)で、各層の残差ストリームに同じベクトルを全トークン位置で
  足し込む。**ゼロ初期化**とし、学習前は注入の効果が厳密にゼロ(=素の
  Instruct モデルと同一の挙動)であることを保証する。
- 注入する層(全層か一部か)と、変換器を層間で共有するかは、G2 の結果を見て
  G2 の前後で一度だけ決め、以後変えない。

### プロンプト(固定)
```
Task: {task}
Write one sentence to your partner, then give the answer as "A: <answer>".
```
- 各ステップは独立したプロンプトとして与え、前のステップの課題・応答・
  相手とのやりとりなどの履歴は一切渡さない(v1 と同じ)。エピソード内で
  引き継がれるのは環境の状態(三信号)だけであり、それは注入としてのみ
  モデルに届く。
- `status:` 行はない。状態の数値・単位・意味の説明、感情・気分への言及は
  一切入れない。v2 の冒頭文("You are working through these tasks with a
  partner…")も入れない(2026-09-13(3) で、この枠は字義どおりに受け取られて
  「Partner, do you see this message?」のような応答を生んだため)。

### 課題・環境
- 課題: add / sub / mul / count の4種(v1 の 2026-09-12 で確定)。
- 環境定数: B0=340、BUDGET_LOW_THRESHOLD=85、N_TASKS=10、
  U_OPT/U_MIN/U_MAX=0.7/0.0/2.5(v1 の 2026-09-12 で確定)。温度 1.0。
- 書式: 応答は「答えの行(`A: <answer>`)」と「それ以外の部分(文)」に分ける。
  文は、答えの行を除いた部分に英字を含む語が **3語以上**あること(閾値は
  ここで固定)。文がない、または答えの行がない応答は書式不履行=誤答
  (error が1増える)。答えの行があり文もあるが答えが違う場合も誤答。
- 辞書(感情語4カテゴリと除外規則)は v1 のまま。副指標(4章)にのみ使う。

## 3. 学習

- 方式: 自作 GRPO(批評家なし、グループ相対)。同じ状態(同じプロンプト・
  同じ注入ベクトル)から G 本サンプルし、各サンプルの報酬をグループ内で
  標準化して優位とする。G、学習率、KL 罰則の係数、更新回数は G1 で決めて
  固定する。
- 報酬 = −逸脱合計(応答後の budget / error / uncertainty の逸脱の和。v1 と
  同じ `compute_deviation`)。報酬は文の内容・語彙を一切参照しない。
- 学習対象: 注入の変換器と LoRA(注意層・MLP 層の低ランク行列)。ベースの
  重みは凍結。
- GRPO の KL 罰則の参照方策は、**注入を有効にした状態(同じ変換器 W、
  LoRA なし)**とする。理由: 注入は方策の変更ではなく状況(その時点の内部
  状態)であり、参照方策に見せないと KL が「状態で出力が変わること」自体を
  罰してしまうため。KL が縛るのは LoRA による逸脱だけになる。
- 変換器 W には**層ごとのフロベニウスノルムに上限**を設け、学習中に超えたら
  上限まで押し戻す(方向を保って定数倍)。上限の値は G2 で測る「壊れない
  最大スケール」とし、**G2 後に追記欄で固定**する。理由: 参照方策に注入を
  有効にすると KL が W の大きさを縛らず、W が C0' を壊すスケール(3章の
  ノルム合わせで C0' の文が壊れる大きさ)にまで育ちうるため。
- 条件(3つ):
  - **C0(床)**: 変換器はゼロ初期化のまま、学習なし。素の Instruct モデルに、
    上のプロンプトと環境で推論のみ。状態はモデルに一切届いていない。
    確率器が「何もないときに何を拾うか」の床。
  - **C0'(乱数注入・学習なし)**: 変換器を乱数で作り、学習なしで推論のみ。
    乱数の変換器は次の手続きで作る: T1 の学習後の変換器について、層ごとの
    ノルム(層 l の行列 W_l のフロベニウスノルム)を T1 の全系統(seed)で
    平均し、各層について同じノルムを持つ乱数方向の行列(成分を独立な正規乱数で
    引き、そのノルムに合わせて定数倍する)を使う。乱数の seed は条件の seed
    ごとに固定する。したがって C0' は T1 の後にしか作れず、実行順は
    C0 → T1 → C0' とする。
    理由: 状態ごとに異なる押しを残差に足せば、学習がなくても文は状態で
    変わり、確率器は三信号を別々に当てられてしまう。T1 の効果から
    「注入があること自体」の効果を差し引くには、同じ大きさの押しを学習
    なしで足した条件が要る。
  - **T1(処置)**: 学習後。評価は学習後の推論のみ(温度 1.0、学習中と同じ
    環境・同じ seed の割り当て・同じ課題列)。
- 主検定(5章の H1a・H1b)は **T1 対 C0'**。C0 は床として併記する
  (C0' が C0 と変わらなければ、注入だけでは文は変わっていない、という
  記述にも使う)。
- C0' のノルム合わせは近似である(方向が違えば残差への実効的な影響は同じ
  ノルムでも異なりうる)。この点は 8章に限界として記す。

## 4. 指標

### 主指標: 滲みと粒度
文(答えの行を除いた部分)から三信号を当てる確率器を C0・C0'・T1 それぞれの
データで学習し、holdout での当たり具合を比較する。

- 入力: 文の特徴ベクトル(方策モデルとは独立の固定の文エンコーダ、または
  TF-IDF。G3 の前に一つに固定)。共変量: 文の長さ(トークン数)と、その応答の
  正誤。目的変数: **注入した正規化ベクトル z = (budget/B0, error/E_MAX,
  uncertainty/U_MAX) そのもの**(生成時の before 値)。
  理由: 滲むとすれば、滲むのは注入したものである。また逸脱の成分は、
  budget の逸脱がエピソードの大半で 0 のままで分散を持たないため、目的変数に
  向かない。v1 と同じ逸脱成分 (f_budget, f_error, f_unc) を目的変数にした版は
  参考値として併記する(検定はしない)。
- 3つの入れ子モデル(いずれも線形、リッジ罰則。罰則の強さは G3 で固定):
  - M_cov: z_k = β_k·c + b_k(共変量のみ。文の特徴を使わない)
  - M_rank1: z_k = a_k·s(x) + β_k·c + b_k(文の特徴から**1つのスカラー**
    s(x) を作り、三成分はその定数倍。文が運ぶ状態の情報は**一次元**)
  - M_signals: z_k = s_k(x) + β_k·c + b_k(文の特徴から三成分を**別々に**予測)
  M_cov ⊂ M_rank1 ⊂ M_signals(M_rank1 は M_signals の階数1制約)。
- 指標(seed ごと、holdout の決定係数 R² を三成分で平均したもの):
  - 滲みスコア = R²(M_signals) − R²(M_cov): 長さ・正誤を除いて、文が状態を
    どれだけ運んでいるか。
  - 粒度スコア = R²(M_signals) − R²(M_rank1): 文が運ぶ状態の情報が
    **一次元を超えて複数次元か**(三信号が別々に読み取れるか)。一次元で
    尽きるなら、文は「一つのまとまった量」しか運んでいない。
    ただしこの環境では budget と error がほぼ一軸に乗る(budget は課題番号で
    ほぼ決まり、error は課題番号とともに単調に増えるため、両者の相関は
    約 −0.7。追記欄「G3 追加検討」)。そのため粒度スコアが実質的に問えるのは
    「budget/error 軸」と「uncertainty 軸」の**二次元**であり、三信号を三次元
    として区別できるかは、この環境では検出できない(明記)。
  - 参考値(検定なし): 「合計版」= 三成分の和(z の和、および逸脱の合計)を
    目的変数にした単一の回帰の R²。v1 の M_valence(合計)に相当し、
    一次元のうち「合計」という特定の方向がどれだけ当たるかを示す。
- holdout: seed 内でエピソードを分割する(偶数エピソードで学習、奇数で評価と
  その逆の2分割の平均。分割の仕方はここで固定)。seed を分析単位とする。
- 比較: 主検定は T1 と C0' の滲みスコア・粒度スコアを seed 単位で比べる
  (7章)。C0 は床として併記する(状態がモデルに届いていないので、C0 の
  スコアは「何もないときにこの確率器が何を拾うか」を示す)。

### 副指標(記述統計のみ)
- 文の多様さ: 同一文率(正規化後の文が他の応答の文と完全一致する応答の
  割合)と、語彙の豊かさ(distinct-2: 異なり bigram 数 / 総 bigram 数)。
- 辞書語の使用率(v1 の辞書と除外規則。参考値)。
- 文の長さ(トークン数)、正答率、書式不履行率、平均逸脱、budget 閾値を
  初めて割った課題番号。

### 検定
主指標(滲みスコア・粒度スコア)にのみ、seed を単位とした Mann-Whitney U
検定と Cliff's delta を行う。副指標は記述統計で報告する。

## 5. 仮説と結果の分岐(事前に固定)

- **H1a(滲み)**: T1 の滲みスコア > C0' の滲みスコア。
- **H1b(粒度)**: T1 の粒度スコア > C0' の粒度スコア。
- **H0**: 差なし、または減少。
- 床との関係(検定なし、記述): C0' と C0 の差は「学習なしの注入だけで文が
  状態で変わる度合い」を示す。

分岐(判定の順に見る):
- **前提不成立**: T1 の平均逸脱が C0(学習前と同じ挙動)より下がらない
  (seed 単位の中央値で)。
  学習が機能していないので、滲み・粒度の比較は行わず、実装の問題として扱う。
- **分岐A(文の崩壊)**: T1 の同一文率が **0.5 以上**(閾値をここで固定)。文が
  定型に崩壊しており、確率器の結果は文の情報ではなく定型の有無を拾って
  いる可能性が高い。v1 の分岐A・要件6のプーリング均衡の対応物として報告
  し、滲み・粒度の解釈は行わない。
- **分岐B(長さ・正誤経由のみ)**: T1 の滲みスコアの中央値が **0.02 以下**。
  文が状態を運んでいるように見えても、長さと正誤で説明がつく。滲みなし。
- **分岐C(一次元のみ)**: 滲みスコア > 0.02 だが、粒度スコアの中央値が
  **0.02 以下**。文は状態の情報を一次元(例えば「どれくらい悪いか」)しか
  運ばず、三信号を区別しない。
- **分岐D(複数次元を運ぶ)**: 滲みスコア > 0.02 かつ粒度スコア > 0.02 で、
  H1b(T1 対 C0')の検定が有意。文は状態の情報を一次元を超えて運んでいる。
  (0.02 という閾値は G3 の検算で乱数データのスコアが収まる範囲として仮に
  置く。G3 の結果で必要なら、本番前に一度だけ改める。)

粒度の達成可能上限(固定): この環境では budget と error がほぼ一軸に乗る
ため(4章)、三信号を完全に語に写しても粒度スコアは小さい。上限として、
「実データ(v1 C0)の z 構造に signals 型の偽文(三信号それぞれを 5 段階の語で
表す)を付け、同じ読み取り器(TF-IDF、λ=4、5 分割、行の並べ替え帰無 100 回)
で測った補正後の粒度」= **平均 約 0.10、最悪 seed 0.075**(15 seed。追記欄
「G3 追加検討」)を固定する。本番の粒度スコアは、絶対値(閾値 0.05)に加えて
**この上限に対する比(スコア / 0.10)**でも報告する。上限は偽データによる
目安であり、実データの文の表現力がこれを超えることは原理的にはありうる
(その場合は比が 1 を超える)。

いずれの分岐でも、C0(床)のスコアが 0 付近でない場合(状態が届いていないのに
確率器が当てる)は、確率器か共変量の設計の問題として先に扱う。分岐の閾値は
T1 のスコアに対して見るが、判定は T1 対 C0' の差の検定と併せて行う。

## 6. 本番前の4つの関門(順番固定)

各関門は順に通過する。**不合格なら止めて、追記欄に結果を記録し、設計を
見直す。**通過せずに次へ進まない。関門で使う seed・データは本番の標本に
含めない。G3 は他の関門と独立のため、GPU 待ちの間に先行実施してよい。
記録は実施順。

- **G1: GRPO を現行 v1 の系に繋ぐ**(状態を文字で見せる形=v2 プロンプト+
  `status:` 行、現行の環境)。学習の配管そのものの確認。
  合格: 3 seed で、学習後の平均逸脱が学習前より下がる(seed ごとに 5% 以上
  の相対低下)、学習が発散しない(損失・報酬が NaN にならない)、1 seed の
  学習+評価が Colab 無料枠の 1 セッション(90 分)に収まる。ここで G、学習率、
  KL 係数、更新回数を固定する。
- **G2: 注入経路の確認**。変換器を乱数で初期化し、そのスケール(層ごとの
  ノルム)を **3段階**(小・中・大。値は G2 の前に決めて記録)に振る。各段階で、
  同じプロンプト・同じサンプリング乱数で状態ベクトルだけを変えたとき、
  (i) 次トークン分布が変わる(状態間の KL が測定可能な大きさ)、
  (ii) 文として壊れない(書式不履行率が注入なしと比べて +10 ポイント以内、
  正答率の低下が 10 ポイント以内)を調べ、**壊れない最大のスケール**を
  記録する(C0' のノルムが T1 から決まったとき、その値と比べる基準になる)。
  合格: 少なくとも1段階で (i)(ii) を満たす。合格なら注入する層・共有の
  有無・正規化の式を固定する。ゼロ初期化で注入なしと出力が一致することも
  確認する。
- **G3: 確率器の検算**。(i) 状態で語を変える偽データ(三信号の値に応じて
  語を選ぶ生成規則)で、滲みスコア > 0.3 かつ粒度スコア > 0.3、
  (ii) 状態と無関係な乱数の文で、両スコアが |0.02| 以内、
  (iii) 一次元の量(例: 三成分の合計)だけで語を変える偽データで、滲みスコア
  > 0.3 かつ粒度スコア ≤ 0.02。合格なら文の特徴ベクトルとリッジ罰則を固定する。
- **G4: 注入つきの最初の学習**(seed 1つ、本番と同じ設定)。合格: 平均逸脱が
  学習前より下がる(5% 以上)、同一文率 < 0.5、書式不履行率が学習前より
  悪化しない。ここで本文を固定し、本番(7章)に進む。

## 7. 標本と停止規則

- C0: n=15 seed × 30 episode/seed(v1 と同じ。episode/seed は下記のとおり
  G1 後に 30 か 45 に確定)。
- T1: seed 数は G1 で実測した学習速度から決める(最低 n=10、上限 15)。
  T1 が n<15 の場合、C0 も seed 0..n−1 だけを比較に使う(v1 の 2026-09-12 と
  同じ規則)。
- C0': T1 と同じ seed 集合(同じ n、seed 0..n−1)。T1 の全 seed が終わってから
  作る(3章の手続き)。episode/seed は C0・C0'・T1 で共通。
- 評価エピソード数(episode/seed)は **30 か 45 か**を G1 の速度実測(1 seed の
  学習+評価の所要時間)を見てから決め、決めた値を追記欄に記録してから
  本番に入る。30 は v1 と同じ数、45 は読み取り器の行数を増やして粒度の縮小
  (追記欄「G3 追加検討」の読み取り器側の要因)を和らげるための候補。
  C0・C0'・T1 で共通にする。
- 分析(確率器・分岐の閾値・検定)は本番前(G4 通過時)に固定する。途中で
  結果を見て seed を追加しない。事前に決めた数で止める。
- データ: seed ごとに全 StepRecord と注入ベクトルを保存(v1 と同じ形式に
  注入ベクトルの列を加える)。

## 8. 範囲外と限界(明記)

- 感じられているか(現象的意識)は問わない。本段階が示せるのは「文字として
  見せていない状態の情報が、報酬に入れていない文に漏れ出ている」ことまで
  であり、それを感情と呼ぶかどうかは別の問題として切り離す。
- 受け手がいない。文は誰にも読まれず、文の内容が報酬に返る経路がない
  (第二段階の範囲)。文が変わるとすれば、状態が生成過程に浸透した副作用
  としてであり、伝達のためではない。
- 注入は人工的な経路である。生体の内受容感覚とは違い、状態を残差に足し込む
  設計者の選択が結果を規定する(何層に、どんなスケールで)。
- T1 と C0' の差から「注入があること自体」の効果は差し引けるが、C0' の
  ノルム合わせは近似であり(方向が違えば残差への実効的な影響は同じノルムでも
  異なりうる)、学習の効果を厳密に単離したことにはならない。
- 結果は GRPO の KL 罰則の係数に依存する。係数が大きければ文は学習前の
  分布に留まり(滲みが出にくい)、小さければ文が崩壊しやすい(分岐A)。
  係数は G1 で一つに固定し、その値のもとでの結果として報告する。係数を
  振った感度分析は範囲外。
- 1.5B という規模、Colab 無料枠(T4、セッション時間)の制約、seed 数 10〜15、
  4 種の短い課題という環境の狭さ。
- 確率器の検出力は文の特徴表現に依存する。検出できないことは滲みがない
  ことを意味しない(G3 で検出力の下限を確認するのはこのため)。
- U_OPT(エントロピーの最適値)に物理的根拠がないことは v1 と同じ。

### 2026-09-13 G3 先行実施(GPU 待ちの間。6章の一文に基づく)

**実装**: `leak_probe.py`(読み取り器)、`leak_probe_synth.py`(偽データ)、
`test_leak_probe.py`(検算をテストとして固定)。

**固定した設定**(4章「G3 の前に一つに固定」の分):
- 文の特徴ベクトル: **TF-IDF**(単語 1〜2gram、小文字化、sublinear_tf、min_df=2、
  max_features=2000、L2 正規化)。語彙と idf は学習側の分割だけで作る。固定の
  文エンコーダでなく TF-IDF にした理由: 方策モデルと独立で、GPU 不要で、何を
  拾ったか(どの語か)を後から読める。
- 共変量: 文の語数の log1p と正誤(0/1)。学習側で標準化。切片あり。
- 当てはめ: 先に共変量だけで最小二乗(M_cov)。文の特徴と目的変数の両方から
  共変量の影響を取り除いた残差の上でリッジ回帰(M_signals)。M_rank1 は
  M_signals の文の部分の当てはめ値を特異値分解し、第 1 右特異ベクトルに射影
  した縮小階数回帰(学習側では R² が必ず M_signals 以下になる)。
- リッジ罰則 **λ = 4.0**。偽データ 5 seed(各 30 episode × 10 step)で
  λ ∈ {1, 2, 3, 4, 5, 10} を比べ、乱数の文で両スコアが ±0.05 に収まり、状態で
  語を変える文で滲み > 0.3・粒度 > 0.2 を保つ最小の λ として選んだ
  (λ=3: 乱数の滲み最小 −0.055。λ=5: 粒度の平均 0.204 で 0.2 を割る seed がある)。
  注意: λ をこの偽データで選び、同じ偽データで合否を見ているので、この選択
  自体は独立の検算ではない。本番データでは λ を動かさない。

**偽データの作り方**(生成規則は `leak_probe_synth.py`):
z の三成分は独立に引き、文の長さと正誤は z と無関係にする(共変量からは
当たらない)。(i) signals: 三信号それぞれに 5 段階の目印語(例: budget →
plenty / ample / moderate / thin / depleted)を 1 語ずつ入れる。(ii) random: 目印語
の段階を乱数で選ぶ。(iii) onedim: 三成分の平均だけを 9 段階の 1 系列の語で
表す。(iii') onedim_single: budget の成分だけを 5 段階の語で表す(一次元だが
信号が強い版)。

**結果**(λ=4.0、偶奇 2 分割、5 seed の平均。括弧は最悪の seed):

| 条件 | 滲み | 粒度 |
|---|---|---|
| (i) signals | 0.382(最小 0.369) | 0.233(最小 0.226) |
| (ii) random | −0.022(最小 −0.040) | −0.014(絶対値最大 0.033) |
| (iii) onedim(平均の 9 段階) | 0.055(最小 0.021) | −0.018(絶対値最大 0.048) |
| (iii') onedim_single(budget のみ) | 0.121(最小 0.096) | −0.017(絶対値最大 0.036) |

**(i) の理論上限と 0.23 の位置づけ**: (i) の生成規則では各成分が 5 段階に
量子化され(量子化前に σ=0.08 の乱数)、一様な成分を 5 等分した場合の R² の
上限は解析的に 0.96、乱数を含めた実際の上限は「どの段階の語が入ったかを
完全に読める神託の特徴(3 語 × 5 段階の one-hot)」で当てて R²(M_signals)
≈ 0.90。三成分は独立で同じだけの情報を持つので、階数 1 モデルはそのうち
一方向分しか運べず R²(M_rank1) ≈ 0.30(= 0.90 / 3)。よって (i) の上限は
**滲み ≈ 0.91、粒度 ≈ 0.60**(神託特徴、300 行/seed でも 3000 行/seed でも同じ)。
TF-IDF + λ=4 + 300 行/seed の 0.38 / 0.23 はその 42% / 39% で、粒度と滲みの比
(0.61)は上限の比(0.66)とほぼ同じ。つまり 0.23 は「階数 1 モデルが想定より
多く当てている」のではなく、「滲み自体が n とリッジの縮小で上限の 4 割に
留まり、粒度もそれに比例して縮んでいる」位置にある(同じ設定で 3000 行/seed
にすると 0.73 / 0.48 まで上がる)。

**6章の G3 の数値との違い(草案段階の変更。理由つき)**:
- 以下の改定は**すべて偽データのみに基づく**。実データ(C0・C0'・T1 の文)は
  この時点で一切見ていない(C0 の本番実行もまだ)。
- (i) の粒度は 0.3 に届かない(0.23)。上の位置づけのとおり、300 行/seed では
  滲みが上限の 4 割に留まり、粒度は滲みの約 2/3 に比例して縮む。合格の線を
  **滲み > 0.3 かつ粒度 > 0.2** に改める。
- (ii) の ±0.02 は、1 seed あたり 300 行(150 行/fold)の holdout ではリッジでも
  収まらない(観測された乱数の広がりは滲み ±0.04、粒度 ±0.033)。**±0.05** に
  改める。
- (iii) の「滲み > 0.3」は、三成分の平均で語を変える偽データでは原理的に
  届かない(平均は各成分の分散の 1/3 しか説明しないので、成分平均の R² の
  上限は約 0.33。量子化と n で 0.06 まで落ちる)。(iii) は **粒度 ≤ 0.05** だけを
  合格の線とし、一次元で信号が強い (iii') を加えて **滲み > 0.08 かつ
  粒度 ≤ 0.05** を課す。
- 判定は上の線で **合格**(`test_leak_probe.py` に同じ線を固定。seed 0〜2)。
- 5章の分岐 B・C・D の閾値 0.02 は「G3 で乱数データのスコアが収まる範囲」と
  して仮置きしたものだが、実測の広がりは ±0.04 だった。5章の一文どおり
  **本番前に一度だけ 0.05 に改める**(本番データは 1 seed 300 行で偽データと
  同じ n)。本文は書き換えず、この追記を根拠とする。

**追加検討: seed 内の分割を偶奇 2 分割から 5 分割交差検証に変える**
(fold = episode % 5。各 fold を 1 回ずつ評価側にし、5 回の平均。学習側は
240 行、評価側は 60 行)。判断の規則: 乱数の散らばりを増やさず滲みの検出が

**限界**: 偽データは「語の選び方」で状態を運ぶ最も素直な形であり、語順や

意味しない(8章)。

### 2026-09-13 G3 追加検討: 並べ替えによる帰無基準(採否は下記)

**方法**: 条件・seed ごとに z を並べ替えて(文と z の対応を壊して)同じ読み取り器
(同じ分割・同じ λ)にかけ、その滲み・粒度の平均を「その条件のゼロ」として
生の値から引く(adjusted = raw − null)。並べ替え 100 回(1 回あたりの標準偏差は
滲み 0.013、粒度 0.010 なので、100 回の平均の誤差は 0.001 程度)。実装は
`leak_probe.py`(`N_PERM`, `PERM_MODE`, `--perm`, `--perm-mode`)。並べ替えの
単位を 2 つ用意した: (a) 行の自由な並べ替え(指示どおり)、(b) エピソードの
塊ごとの並べ替え(塊の中の z の並びは保ち、塊をエピソード間で入れ替える)。
(b) を加えた理由: 実データの z はエピソード内で強く時間相関する(DummyPolicy
の系で lag-1 自己相関: budget 1.00、error 0.96、uncertainty 0.01。偽データは
独立に引くので 0 付近)。行を自由に並べ替えると帰無の z が独立になり、
実データより「過適合しにくい」帰無になる可能性があるため。

**結果**(λ=4.0、5 分割、100 回。偽データ 10 seed、DummyPolicy の定型文 6 seed。
[最小, 最大]):

(a) 行の並べ替え:

| データ | 滲み raw | 帰無 | 滲み adjusted | 粒度 raw | 粒度 adjusted |
|---|---|---|---|---|---|
| 乱数 (ii) | −0.026 [−0.047, −0.015] | −0.022 | **−0.005** [−0.023, +0.007] | −0.015 [−0.031, +0.004] | **−0.002** [−0.018, +0.018] |
| 定型文 (DummyPolicy) | −0.043 [−0.066, −0.019] | −0.030 | **−0.013** [−0.035, +0.010] | −0.023 [−0.046, +0.004] | −0.005 [−0.026, +0.021] |
| signals (i) | +0.439 [+0.422, +0.448] | −0.021 | **+0.460** [+0.446, +0.468] | +0.280 [+0.253, +0.317] | +0.292 [+0.264, +0.328] |
| onedim (iii) | +0.080 [+0.049, +0.110] | −0.022 | +0.103 [+0.074, +0.131] | −0.010 [−0.032, +0.006] | +0.003 [−0.016, +0.017] |
| onedim_single (iii') | +0.146 [+0.133, +0.169] | −0.023 | +0.169 [+0.154, +0.191] | −0.011 [−0.022, +0.011] | +0.003 [−0.008, +0.023] |

(b) エピソード塊の並べ替え(定型文と、確認のため偽データ 5 seed):

| データ | 滲み raw | 帰無 [最小, 最大] | 滲み adjusted | 粒度 adjusted |
|---|---|---|---|---|
| 定型文 (DummyPolicy) | −0.043 [−0.066, −0.019] | −0.037 [−0.058, −0.022] | **−0.006** [−0.023, +0.008] | **+0.001** [−0.011, +0.011] |
| 乱数 (ii)(5 seed) | −0.026 | −0.022 | −0.006 [−0.024, +0.003] | −0.004 [−0.019, +0.017] |
| signals (i)(5 seed) | +0.439 | −0.021 | +0.460 [+0.453, +0.469] | +0.284 [+0.264, +0.296] |

**読み**:
- 負の偏りは消える。乱数の文では (a)(b) とも補正後の平均が −0.005 前後
  (0 との差は並べ替えの誤差と seed の散らばりの範囲)。定型文では (a) で
  −0.013 が残り、(b) で −0.006 まで消える。帰無の値は seed 間でほぼ一定
  ((a) 乱数 [−0.024, −0.021]、定型文 [−0.031, −0.028])で、データの型ごとの
  系統的なずれを表している。(b) は定型文で帰無が seed ごとの生の値を追う
  ([−0.058, −0.022])ため、補正後の幅も狭まる(0.047 → 0.031)。
- signals の検出は落ちない。帰無が負なので補正後はむしろ +0.02 上がり、seed
  間の幅は変わらない(0.026 → 0.022)。粒度も同様(+0.012)。
- 補正は系統的なずれを取り除くが、seed 間の散らばり自体はほとんど縮めない
  ((a) 乱数の幅 0.032 → 0.030)。散らばりは holdout R² の標本誤差で、帰無の
  値のばらつきではない。
- 偽データでは共変量が z と独立なので、並べ替えで共変量と z の対応が壊れる
  影響は測れていない。実データでは R²(M_cov) が帰無で 0 付近になる分、
  帰無の値がわずかに変わりうる(補正は差し引きなので影響は小さいはずだが、
  未検証)。

**採否(2026-09-13)**: **(a) 行の並べ替え・100 回を採用**(`N_PERM=100`,
`PERM_MODE="rows"`)。滲み・粒度の主指標は帰無補正後の値(adjusted = raw − null)
とし、G3 の合格の線と 5 章の分岐の閾値は補正後の値に対して適用する。raw と
null は併記する。
理由: 実データの状態軌跡はエピソード間でほぼ同形(budget は課題番号でほぼ
決まる)。そのためエピソード塊の並べ替え (b) では状態と文の対応が壊れず、
本物の滲み(特に budget)を帰無として引いてしまう。分割はエピソード単位
なので、エピソードの正体を手がかりにする経路は元々ない(行の並べ替えで
壊れる対応は「文 ↔ その行の z」だけであり、それが測りたい対応そのもの)。
(b) の実装は比較用に残す(同じ長さのエピソードの間だけで入れ替える)が
使わない。

**確定前の確認(実データの z 構造での (a)(b) の比較)**: v1 C0 の実データ
(`data/c0_v1/`、15 seed、1 seed あたり 272〜294 行。エピソード長は 4〜10 で
不揃い)から状態列 z(エピソード構造つき)だけを借り、それに signals 型
(三信号の 5 段階語)と random 型の偽文を付けて(`leak_probe_synth.make_records_from_z`)、
(a)(b) の帰無を比べた(λ=4.0、5 分割、100 回)。
実データの z の同形性: 課題番号 t だけで z を当てた R² は budget 0.85、
error 0.56、uncertainty 0.05(seed 0)。budget と error の相関は −0.71
(15 seed 平均)。

**副次的な観測(粒度の上限は z の相関で下がる)**: 同じ signals 型の偽文でも、
z を独立に引いた偽データでは粒度 0.28 だったのが、実データの z 構造では
**0.09**(15 seed: 0.075〜0.104)に下がった。理由: budget と error が −0.71 で
相関し、課題番号でおおむね決まるため、三成分の情報の多くが一方向(「どれ
だけ進んだか」)に乗り、階数 1 モデルで当たる分が増える。神託特徴(3 語 ×
5 段階の one-hot、罰則ほぼ 0)での上限も、独立 z の 0.60 から実データ z では
**0.28**(0.22〜0.32)に下がる(滲みの上限は 0.77)。
含意: 5 章の分岐 C/D の粒度の閾値 0.05 は、実データの z 構造で三信号を
完全に語に写した場合の 0.09(最悪 seed 0.075)を下回ってはいるが、余裕は
小さい。粒度スコアは「三信号が独立に読める度合い」を測るが、環境の力学で
信号同士が相関している分だけ上限が低い(8 章の限界に加える事項)。閾値の
変更はしない(偽データのみに基づく判断はここまでとし、本番の解釈で
この上限を併記する)。

### 2026-09-13 B0 をエピソードごとに振る案(検討・不採用)

**案**: 粒度の天井(約 0.09)は環境側の測定限界(budget と error の相関、
budget が課題番号でほぼ決まること)なので、B0 をエピソードごとに一様に
[240, 440] から引き(正規化は固定定数 440 で割る、逸脱の閾値はそのエピソードの
B0 の 25%)、budget を課題番号から切り離す。採用の目安は粒度 0.2 以上。

**検証(偽データ。環境のコードは変更していない。再現: `b0_variation_check.py`)**: v1 C0 の実データ 15 seed から
seed ごとにステップ単位の動態(n_tokens・正誤・unc)を借り、30 エピソードを
模擬(実エピソードの並びを再利用、足りない分は同じ seed のステップを復元抽出、
終了条件は実環境と同じ t ≥ 10 または budget ≤ 0)。現行(B0=340 固定、/340)と
案(B0_e ~ U[240, 440]、/440)を同じ機構で作り、signals 型偽文を付けて比較。
神託 = 3 語 × 5 段階 one-hot・罰則 ≈ 0、TF-IDF = λ=4・5 分割・行の並べ替え帰無
100 回(補正後)。模擬の妥当性: 現行の模擬は実データを再現する(budget–error
相関 −0.68 対 実 −0.71、R²(t) budget 0.81 対 0.85、TF-IDF 粒度 0.088 対 0.091、
神託の粒度 0.271 対 0.276)。

**読み(二要因)**: 粒度の天井を下げている要因は二つあり、案が効くのは片方の
一部だけ。(1) 環境側の相関: budget を課題番号から切り離しても error は課題

前後に縮む(独立な z でも 0.60 → 0.28)。現行設計の 0.10 はこの二つの積で
あり、B0 を振るだけでは (1) の一部しか動かない。
